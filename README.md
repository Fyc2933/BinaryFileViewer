# 二进制文件查看器

一个图形化的文件选择工具，能够将所选文件的内容以二进制编码形式进行展示。

## 功能特点

- 🖼️ **图形化界面**：基于Tkinter的现代化用户界面
- 📁 **文件选择**：支持选择任意类型的文件
- 🔢 **二进制显示**：以十六进制格式显示文件内容
- 📊 **ASCII预览**：可选显示ASCII字符预览
- ⚙️ **自定义设置**：可调整每行显示的字节数
- 📏 **文件大小检测**：自动检测大文件并提示
- 🎯 **地址偏移**：显示每个字节的偏移地址

## 系统要求

- Windows 7/8/10/11

## 使用说明

1. **选择文件**：点击"选择文件"按钮，选择要查看的文件
2. **查看内容**：文件内容将以十六进制格式显示
3. **调整设置**：
   - 勾选/取消"显示ASCII字符"来切换ASCII预览
   - 调整"每行字节数"来改变显示密度
4. **清空显示**：点击"清空显示"按钮重置界面

## 界面说明

- **顶部**：显示当前选择的文件路径
- **中部**：二进制内容显示区域，包含：
  - 地址偏移量（十六进制）
  - 十六进制字节表示
  - ASCII字符预览（可选）
- **底部**：状态栏显示文件大小和操作状态

## 注意事项

1. 对于大文件（>10MB），程序会提示确认是否继续显示
2. 程序会自动处理文件读取错误和异常情况
